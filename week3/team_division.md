# 第三周组内分工表

## 小组信息
- **项目名称**：API Token 中转站数据库项目
- **小组成员**：阮依成、陈诗翰、肖懿
- **第三周任务**：DDL 与数据修改

## 分工明细

| 成员 | 分工 | 主要职责 |
|---|---|---|
| 阮依成 | 测试、写文档 | 执行 SQL Server 复现测试、CRUD 与约束验证；整理测试结果、截图和第三周交付文档。 |
| 陈诗翰 | 代码 | 编写和整理建库、建表、样例数据及 CRUD 脚本；根据测试反馈修改代码。 |
| 肖懿 | 思路设计 | 设计第三周实现方案、数据生成思路和业务一致性规则；审核代码与课程要求的符合性。 |

## 协作要求
- 代码修改后由阮依成复测并记录结果。
- 陈诗翰根据测试问题修改代码。
- 肖懿负责确认业务逻辑、实现思路和最终版本。
- 三人共同核对 AI 使用记录及阶段交付材料。
