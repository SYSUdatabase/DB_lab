03 / 三个容易混淆的地方

Token 的三种记录，不是一回事

商品套餐（Products）

定义销售什么：例如一种 provider 的某档 Token 数和销售价格。它是商品目录，不是库存。

用户余额（TokenBalances）

记录用户在某个 provider 下还能使用多少 Token。支付入账和调用扣减属于业务事务规则。

上游额度（Inventory）

平台从上游账号获得的剩余配额。用户调用时，上游额度也会变化；它不等于用户余额。

v1.0 规范化的主要变化原来的 UsageSummary 拆为 UsagePeriod + UsageSummaryCore。旧名称 UsageSummary 现在是只读兼容视图，不是第 16 张物理表。数据库结构迁移与相应回归已完成，但源库继承的时间顺序与历史余额异常仍有未通过项。
