## 展示前准备

### 0.1 环境与窗口

1. 在PowerShell进入`D:\Desktop\DB\DB_lab`，按[README复现与启动流程](../README.md)选择新建库或已有库补装路径，记录本轮RunId及v1.1库名。

需要同时展示数据库库存扣减时，在SSMS选中本轮v1.1库，点“新建查询”，粘贴以下只读SQL，按F5。查询已写入本流程使用的`chen_demo`账号，可直接粘贴执行。

```sql
SELECT TOP (1) l.log_id,l.tokens_used,l.upstream_tokens_consumed,l.account_id,
       a.account_name,a.total_quota,a.used_quota,i.current_quota,
       a.total_quota-a.used_quota AS expected_current_quota
FROM dbo.TokenUsageLogs l
JOIN dbo.Users u ON u.user_id=l.user_id
JOIN dbo.UpstreamAccount a ON a.account_id=l.account_id
JOIN dbo.Inventory i ON i.account_id=a.account_id
WHERE u.username='chen_demo'
ORDER BY l.log_id DESC;
```

本套餐1:1换算，本次上游消耗20000。用account_id说明实际消耗账号，库存等式应相符。第11页继续展示补货。

## PPT第3页：第二阶段成果与证据

## PPT第6页：规范化迁移与数据保留

**核心功能**　将周期定义从使用汇总中拆出，验证记录保留与无损重构。

SELECT COUNT_BIG(*) AS summaries FROM dbo.UsageSummaryCore;

SELECT TOP (5) period_type,period_start,period_end
